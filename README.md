# Student Grade Analysis

A simple **Java console-based application** that performs grade analysis for a class of students.  
This project demonstrates **core Java concepts** such as arrays, loops, conditionals, switch-case, and user input handling.

---

## Features
- **Enter Student Grades**  
  - Input grades for up to 20 students.  
  - Validates grades (0–100). Invalid entries are set to 0.

- **Calculate Class Average**  
  - Computes the average grade of the class.  

- **Find Highest and Lowest Grades**  
  - Identifies the maximum and minimum grades among students.  

- **Pass/Fail Count**  
  - Passing grade is set at **35**.  
  - Displays total students, number of passes, and number of fails.  

- **Exit Option**  
  - Gracefully terminates the program.

---

## Tech Stack
- **Language**: Java  
- **Concepts Used**: Scanner class, arrays, loops (`for`, `while`), switch-case, conditional statements.

---

## Project Structure
- `EnterGrade()` → Accepts and validates student grades.  
- `Calculate()` → Computes class average.  
- `hlgrades()` → Finds highest and lowest grades.  
- `passfails()` → Counts pass and fail students.  
- `main()` → Menu-driven program loop.
